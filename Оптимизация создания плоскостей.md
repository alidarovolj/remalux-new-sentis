# 🎯 Оптимизация системы создания AR плоскостей

## Проблема
Система создает слишком много мелких плоскостей (например, 133 плоскости для 2 стен), что приводит к:
- Низкой производительности
- Визуальному шуму
- Неточному представлению реальных поверхностей

## ✅ Внесенные оптимизации

### 1. Увеличены пороги фильтрации мелких областей
- `minPlaneSizeInMeters`: 0.1f → 0.6f
- `minPixelsDimensionForArea`: 1 → 20
- `minAreaSizeInPixels`: 150 → 1500
- `maskProcessingResolution`: 128 → 256

### 2. Улучшены параметры размеров плоскостей
- `minPlaneSize`: 0.3f → 0.8f
- `maxAspectRatio`: 6.0f → 4.0f (более квадратные плоскости)
- `sizeReductionFactor`: 0.8f → 0.95f (сохранение размера)
- `wallFitMultiplier`: 0.5f → 0.8f

### 3. Ужесточены фильтры качества
- `minWallRatio`: 0.4f → 0.6f (60% пикселей должны быть стеной)
- `maxAreaAspectRatio`: 8.0f → 5.0f (менее вытянутые области)

### 4. Отключено динамическое слияние
- `enableDynamicMerging`: false (по умолчанию для стабильности)

### 5. Отключено детальное логирование
- `enableCustomPlaneCreationLogging`: false
- `enableDetailedRaycastLogging`: false

## 🚀 Быстрые настройки

В Inspector компонента `ARManagerInitializer2` доступны контекстные меню:

### Консервативные настройки
*Правый клик → "Применить консервативные настройки"*
- Создает умеренное количество крупных плоскостей
- Хороший баланс между точностью и производительностью

### Строгие настройки
*Правый клик → "Применить максимально строгие настройки"*
- Создает минимальное количество только крупных плоскостей
- Максимальная производительность, но может пропускать мелкие детали

## 📊 Ожидаемый результат

**Было**: 133 плоскости для 2 стен
**Стало**: 2-8 крупных плоскостей, точно представляющих стены

## 🔧 Ручная настройка

Для тонкой настройки системы используйте следующие параметры в Inspector:

### Фильтрация мелких областей
```
minPlaneSizeInMeters: 0.6f - 1.2f
minAreaSizeInPixels: 1500 - 4000
minPixelsDimensionForArea: 20 - 40
```

### Качество областей
```
minWallRatio: 0.6f - 0.8f
maxAreaAspectRatio: 3.0f - 5.0f
```

### Размеры плоскостей
```
minPlaneSize: 0.8f - 1.5f
maxAspectRatio: 2.5f - 4.0f
```

## ⚠️ Отладка

Если нужна диагностика:
1. Включите `enableCustomPlaneCreationLogging`
2. Проверьте консоль на сообщения с префиксом `[ARManagerInitializer2]`
3. Отследите количество созданных плоскостей в логах

## 🎮 Динамическое слияние (опционально)

Если нужно объединить существующие мелкие плоскости:
1. Включите `enableDynamicMerging`
2. Настройте `dynamicMergingRadius` (1.0f - 2.0f)
3. Вызовите `ManuallyMergePlanes()` через код или Inspector

**Внимание**: Динамическое слияние может вызывать мерцание плоскостей при частом использовании.
