# PlaneGeometryEnhancer - Улучшение точности геометрии плоскостей

## Обзор
`PlaneGeometryEnhancer` - это новый класс, созданный для значительного улучшения точности углов и размеров создаваемых AR плоскостей. Он предоставляет более сложные алгоритмы по сравнению с базовой реализацией в `ARManagerInitializer2`.

## Ключевые улучшения

### 1. Адаптивный рейкастинг
- **Переменная плотность лучей**: количество лучей адаптируется под размер области сегментации
- **Концентрические круги**: лучи распределяются кольцами с убывающими весами от центра
- **Диапазон**: от 5 до 25 лучей в зависимости от размера области

### 2. Продвинутая кластеризация
- **Группировка по расстоянию**: толерантность 0.2м между точками попадания
- **Группировка по углу**: толерантность 15° между нормалями поверхности
- **Взвешенное усреднение**: итоговый результат основан на весах уверенности

### 3. Стабилизированная ориентация
- **Мировая вертикаль**: использует Vector3.up как базовую ось для стабильности
- **Обработка крайних случаев**: специальная логика для поверхностей, близких к вертикали

### 4. Точный расчет размеров
- **Компенсация перспективы**: проецирование углов области на плоскость поверхности
- **Локальная система координат**: размеры вычисляются в координатах плоскости
- **Сглаживание артефактов**: минимальные размеры для избежания нулевых значений

### 5. Система оценки уверенности
- **Фактор расстояния**: ближе = лучше
- **Фактор выравнивания нормали**: вертикальные стены получают больший вес
- **Качество поверхности**: MeshCollider > BoxCollider > прочие

## Инструкции по активации

1. **Откройте Unity Editor**
2. **Проверьте компиляцию**: убедитесь что нет ошибок в Console
3. **Включите Enhanced режим**:
   - Найдите компонент `ARManagerInitializer2` в сцене
   - Установите `Use Enhanced Plane Geometry = true`
   - Опционально включите `Enable Enhanced Geometry Logging = true`

## Производительность

### Оценки
- **Стандартный алгоритм**: 1 рейкаст
- **Улучшенный алгоритм**: 5-25 рейкастов + кластеризация
- **Ожидаемое замедление**: 3-5x для создания каждой плоскости
- **Воздействие на FPS**: минимальное (плоскости создаются не каждый кадр)

### Оптимизации
- Адаптивное количество лучей снижает нагрузку для маленьких областей
- Ранний выход при отсутствии валидных попаданий
- Кеширование результатов рейкастинга

## Логирование

При включенном `enableEnhancedGeometryLogging` система выводит:
- Количество валидных попаданий рейкастинга
- Размеры созданных плоскостей
- Уровень уверенности результата
- Причины отклонения плоскостей
