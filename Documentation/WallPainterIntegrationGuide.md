# Руководство по интеграции WallPainter - новой архитектуры генерации плоскостей

## Обзор

Новая архитектура WallPainter решает проблему маленьких красных плоскостей, заменяя неэффективный массовый рейкастинг на интеллектуальную систему обработки контуров. Теперь одно касание пользователя создает точную, полноразмерную плоскость стены.

## Архитектура решения

### Основные компоненты:
1. **WallPainterController** - главный оркестратор процесса
2. **FloodFill** - алгоритм выделения связной области по касанию
3. **MarchingSquares** - извлечение векторного контура из растровой маски
4. **EarClippingTriangulator** - триангуляция полигонов любой сложности

### Поток данных:
```
Касание пользователя → Маска сегментации → Flood Fill → 
→ Извлечение контура → Проецирование в 3D → Триангуляция → 
→ Процедурный меш
```

## Пошаговая интеграция

### Шаг 1: Подготовка сцены

1. Откройте вашу AR сцену
2. Найдите GameObject с `ARSessionOrigin` или `XR Origin`
3. Добавьте компонент `WallPainterController` на этот объект

### Шаг 2: Создание префаба плоскости

1. Создайте новый пустой GameObject
2. Добавьте компоненты:
   - `MeshFilter`
   - `MeshRenderer`
   - `MeshCollider`
3. Создайте материал для покраски стен:
   - Создайте новый материал
   - Используйте шейдер "Universal Render Pipeline/Lit" или ваш кастомный
   - Настройте базовый цвет и другие параметры
4. Сохраните как префаб в папке `Assets/Prefabs/WallPlanePrefab.prefab`

### Шаг 3: Настройка WallPainterController

В инспекторе Unity настройте следующие параметры:

#### Основные компоненты:
- **Wall Segmentation**: Автоматически найдется или укажите вручную
- **AR Camera**: Обычно Main Camera
- **Raycast Manager**: Компонент ARRaycastManager

#### Визуализация:
- **Wall Plane Prefab**: Перетащите созданный префаб
- **Wall Paint Material**: Материал для покраски

#### Параметры:
- **Segmentation Confidence**: 0.75 (порог уверенности)
- **Max Raycast Distance**: 5.0 (максимальная дистанция)
- **Min Contour Area**: 1000 (минимальная площадь в пикселях)
- **Contour Simplification Tolerance**: 2.0 (упрощение контура)

### Шаг 4: Отключение старых компонентов

Найдите и отключите следующие компоненты (если есть):
- `RaycastController`
- `WallPlaneController`
- Любые скрипты с массовым рейкастингом

### Шаг 5: Тестирование

1. Запустите сцену на устройстве или в симуляторе
2. Направьте камеру на стену
3. Коснитесь стены на экране
4. Должна появиться полноразмерная плоскость, точно соответствующая контурам стены

## Настройка производительности

### Для высокой производительности:
```
Segmentation Confidence: 0.8
Min Contour Area: 2000
Contour Simplification Tolerance: 5.0
```

### Для высокой точности:
```
Segmentation Confidence: 0.6
Min Contour Area: 500
Contour Simplification Tolerance: 0.0
```

## Отладка

### Включение режима отладки:
1. Установите `Debug Mode` = true
2. Установите `Show Contour Visualization` = true
3. Создайте материал для отладочного контура (например, ярко-зеленый)

### Что проверять:
- В консоли появляются логи каждого этапа
- Зеленый контур показывает извлеченную форму стены
- Сообщения об ошибках укажут на конкретный этап сбоя

## Расширенные возможности

### Обработка нескольких стен:
```csharp

```

### Кастомная обработка касаний:

## Решение проблем

### Проблема: Плоскость не создается
**Решение**: 
- Проверьте, что WallSegmentation работает и генерирует маску
- Увеличьте Debug Mode и проверьте логи
- Уменьшите Min Contour Area

### Проблема: Плоскость неправильной формы
**Решение**:
- Уменьшите Contour Simplification Tolerance
- Проверьте качество маски сегментации
- Увеличьте Segmentation Confidence

### Проблема: Низкая производительность
**Решение**:
- Увеличьте Contour Simplification Tolerance
- Увеличьте Min Contour Area
- Уменьшите разрешение маски в WallSegmentation
