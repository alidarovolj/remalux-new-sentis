# 🔧 Руководство по исправлению размеров плоскостей

## 🎯 Проблема
Система создавала плоскости со слишком большими размерами:
- Вместо реалистичных 2.0м × 2.2м создавались плоскости 4.36м × 2.77м
- Высота стен достигала 3.82м (нереалистично для обычных помещений)
- Ширина стен превышала 6.02м

## ✅ Решение - Обновленные ограничения

### Новые лимиты размеров:
- **Максимальный размер плоскости**: 2.5м (было 3.5м)
- **Максимальная высота стены**: 2.5м (было 2.8м)  
- **Максимальная ширина стены**: 3.0м (было 4.0м)
- **Коэффициент масштабирования**: 0.4 (было 0.6) - более агрессивное уменьшение
- **Максимальное соотношение сторон**: 4:1 (было 6:1)

### Автоматическая очистка:
Система теперь автоматически удаляет плоскости, которые:
- Превышают максимальные размеры
- Имеют неправильное соотношение сторон  
- Слишком маленькие (менее 0.5м)

## 🛠️ Инструменты для управления

### 1. Автоматическое исправление (уже работает)
Система автоматически:
- Удаляет большие плоскости каждые 3 секунды
- Создает новые плоскости с правильными размерами
- Логирует процесс в консоль

### 2. Ручные инструменты через Unity Editor

#### В меню `Tools`:
- **🔥 Добавить PlaneResetTool к сцене** - добавляет инструмент управления
- **📊 Анализ текущих плоскостей** - показывает размеры всех плоскостей
- **🗑️ Удалить все большие плоскости** - удаляет только проблемные плоскости
- **🔥 ЭКСТРЕННЫЙ СБРОС** - удаляет ВСЕ плоскости для перезапуска

#### Горячие клавиши:
- **Ctrl+R** - Принудительное пересоздание всех плоскостей
- **Ctrl+D** - Удаление только больших плоскостей

### 3. PlaneResetTool компонент

#### Автоматические функции:
- `autoReset = true` - автоматически пересоздает плоскости при запуске
- Мониторинг размеров плоскостей в реальном времени

#### Контекстное меню (правый клик на компоненте):
- **🔥 ПРИНУДИТЕЛЬНО ПЕРЕСОЗДАТЬ ВСЕ ПЛОСКОСТИ**
- **📊 Анализ текущих плоскостей** 
- **🗑️ Удалить только большие плоскости**

# Руководство по исправлению проблемы с генерацией плоскостей из сегментации

## Текущая ситуация

1. **Сегментация работает корректно** - маски генерируются с 80-100% обнаружением стен
2. **Обработка масок работает** - метод `ProcessSegmentationMask()` вызывается
3. **Плоскости НЕ создаются** - статистика показывает 0 плоскостей от сегментации
4. **Синие плоскости** - это стандартные плоскости ARFoundation, а не наши

## Анализ проблемы

Судя по логам, проблема может быть в одном из следующих мест:

### 1. Размер областей слишком мал
Текущая настройка `minAreaSizeInPixels = 150` может быть слишком большой для областей, найденных в маске сегментации.

### 2. Проблемы с рейкастингом
Рейкасты могут не попадать в коллайдеры в сцене из-за:
- Отсутствия коллайдеров в симуляции
- Неправильной настройки LayerMask
- Слишком малого расстояния рейкаста

### 3. Проблемы с координатами
UV координаты из маски могут неправильно преобразовываться в экранные координаты для рейкастинга.

## Рекомендации по отладке

### 1. Проверьте размер минимальной области
В Unity Inspector компонента `ARManagerInitializer2`:
- Уменьшите `Min Area Size In Pixels` до 50 или даже 25
- Это позволит создавать плоскости для меньших областей

### 2. Проверьте настройки рейкастинга
- `Max Ray Distance` должно быть достаточно большим (например, 10м)
- `Hit Layer Mask` должна включать слои с коллайдерами (Default, SimulatedEnvironment)
- `Min Hit Distance Threshold` не должно быть слишком большим (0.1-0.5м)

### 3. Включите логирование
В компоненте `ARManagerInitializer2`:
- Включите `Enable Custom Plane Creation Logging`
- Включите `Enable Cleanup Logging`

### 4. Проверьте наличие коллайдеров
Запустите сцену и проверьте в логах:
- Должны появиться сообщения о количестве коллайдеров
- Если коллайдеров 0, система не сможет создать плоскости

### 5. Альтернативный подход - создание плоскостей без рейкастинга
Если рейкастинг не работает, можно временно создавать плоскости прямо перед камерой на фиксированном расстоянии.

## Быстрое решение

1. В Unity Inspector найдите `ARManagerInitializer2`
2. Измените следующие параметры:
   - `Min Area Size In Pixels` = 25
   - `Max Ray Distance` = 10
   - `Min Hit Distance Threshold` = 0.1
   - Включите все флажки в разделе "Debug Settings"

3. Запустите сцену и посмотрите логи - теперь должна быть видна подробная информация о процессе создания плоскостей.

## Следующие шаги

После изменения настроек и анализа логов:
1. Если области слишком малы - продолжайте уменьшать `Min Area Size In Pixels`
2. Если рейкасты не попадают - проверьте коллайдеры и LayerMask
3. Если плоскости создаются, но не видны - проверьте материалы и слои
